# Microchip P1 Phase 1 — source-locked original MCP × DS60001513G ordering audit

**Research-only:** evaluate the existing 126 exact commercial Microchip P1 ICPNs
and 12 SAM L10/L11 manufacturer Base Devices against manufacturer ordering
rules. P1 is **research priority**, not Phase 1 status or software support.

## Do not conflate program Flash and Data Flash

| Manufacturer series | Density 14 | Density 15 | Density 16 |
|---|---|---|---|
| L10 D/E | Main Flash 16 KB, Data Flash 2 KB, SRAM **4 KB** | Main 32 KB, Data 2 KB, SRAM 8 KB | Main 64 KB, Data 2 KB, SRAM 16 KB |
| L11 D/E | Main Flash 16 KB, Data Flash 2 KB, SRAM **8 KB** | Main 32 KB, Data 2 KB, SRAM 8 KB | Main 64 KB, Data 2 KB, SRAM 16 KB |

D group has 24 pins and VQFN/SSOP packaging. E group has 32 pins and
VQFN/TQFP/WLCSP packaging. Datasheet p.16 assigns: package code
A=TQFP, M=VQFN, Y=SSOP, U=WLCSP; grade U=-40~+85°C,
F=-40~+125°C, Z=-40~+125°C with AEC-Q100 Grade 1.
Z grade is restricted to TQFP and VQFN. Suffix T means tape-and-reel;
no carrier suffix means tray/tube. Optional KPH applies only to SAM L11
with TQFP/VQFN and indicates factory security-key provisioning.
WLCSP packages have a factory-programmed bootloader; separate software
qualification is needed for that condition.

## Exact ICPN Research verification contract

The new program microchip_phase1_p1_ordering_crosswalk_v1.py consumes
**only original-MCP-source-replayed existing commercial part numbers**
from microchip_phase1_p1_information_ledger_v1.py and the pinned official
PDF original; it never generates plausible SKUs.

- A source-existing exact ICPN is parsed and checked against Base identity,
  factory carrier, package, grade, security suffix and manufacturer
  restrictions. Its interpretation is source-traced to both original MCP
  and original PDF SHA receipts.
- Code states: MCP_EXACT_CODE_MATCHES_PDF_ORDERING_GRAMMAR;
  UNPARSED_ORIGINAL_MANUFACTURER_ORDER_CODE;
  ORDERING_PDF_RESTRICTION_CONFLICT; BASE_PREFIX_IDENTITY_CONFLICT.
  Every original P1 ICPN remains in the output.
- The tool replays all twelve printed p.14 main/Data Flash + SRAM rows
  and checks p.16 code values from archived PDF text; it fails closed on
  original-byte tampering, document revision drift and table value mismatch.
- Real code-state counts and exceptions are generated by the original-source
  replay job in GitHub Actions, archived alongside the 126-row input ledger.
  Synthetic tests alone **do not establish manufacturer coverage**.

**Explicit boundaries:** This is a research compatibility check, **not a Phase 1
VERIFIED field promotion**. New VERIFIED fields=0, record-level complete=0,
Production admission=0, Selector changes=0, OpenOCD SUPPORTED=0,
Programming/Flash Driver/HIL qualification=0. The previously merged 2,437 P0
source-verified ICPNs remain separate.

## Actual 126-ICPN source replay and four automotive extensions

The real original-MCP + PDF replay on
[GitHub Actions run 38678052081](https://github.com/physicslu/plasma/actions/runs/38678052081)
first found **122 ordinary DS60001513G ordering-grammar matches** and
**4 exact manufacturer-MCP ICPNs that have an additional VAO suffix**:

| Original manufacturer MCP exact ICPN | Base Device | Special suffix |
|---|---|---|
| ATSAML10D16A-MZTVAO | ATSAML10D16A | VAO |
| ATSAML10E16A-MZTVAO | ATSAML10E16A | VAO |
| ATSAML10E16A-MZVAO | ATSAML10E16A | VAO |
| ATSAML11E16A-MZTVAO | ATSAML11E16A | VAO |

Manufacturer's [Recommended for Automotive Designs / Automotive Ordering Codes](https://www.microchip.com/en-us/solutions/automotive-and-transportation/recommended-for-automotive)
explicitly identifies **VAO** as an automotive-standard order-code suffix.
The policy also says a VAO suffix does **not** include PPAP documentation;
additional custom automotive ordering requirements use separate numbers.
This official manufacturer policy is an online source located for further
evidence capture, **not yet replayed from original publisher bytes in this
crosswalk**. The family PDF p.16 does not contain the VAO extension.

Engineering decision: classify these four exact original-MCP identities as
**MCP_VAO_SPECIAL_SUFFIX_SEPARATE_SOURCE_REVIEW_REQUIRED**, not as missing
commercial parts or ordinary PDF-only codes. Preserve both the original
manufacturer Base identity and VAO warning, but produce **zero** exact-field
VERIFIED promotions or hardware/programming compatibility claims. Separate
automotive packaging, process qualification and blank-device assumptions
require official source checks before Phase 2 programming decisions.
