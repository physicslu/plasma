# OpenOCD Current Gap Rebaseline v6.17

Research-only reclassification of the Production OpenOCD route gap after the v6.16 backend mapping transaction.

## Purpose

Do not carry the old 956-row Tier A/B/C/D partition forward as if it were still current.

This pass rescans the current Production catalog and classifies every remaining `no_mapping` identity from the new post-v6.16 state.

The classification preserves the frozen upstream OpenOCD baseline used by v6.3 so the before/after comparison remains meaningful.

## Current Production boundary

- Production exact identities: **4,629**
- mapped: **4,037**
- no_mapping: **592**
- Active OpenOCD route: **3,958 / 4,550 = 86.9890%**

## Reclassification semantics

- **A residual** — same family + series now has mapped siblings with one consistent target config.
- **B** — exact series has no mapped sibling, but the frozen upstream family target has a Flash bank.
- **C** — upstream family target exists but has no Flash bank.
- **D** — no direct family target exists in the frozen upstream target inventory.

This is route-gap classification only. It does not infer identifiers, bind Programming Profiles, or claim erase/program/verify, Engineering Verified, or HIL status.

The exact post-v6.16 tier counts are generated by CI from the current Production files rather than copied from the pre-v6.16 report.
