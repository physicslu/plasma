# STM32F4 Phase 4.2 — Policy Blocker Taxonomy

Phase 4.2 starts after the Phase 4.1 R/T admission work reduced the STM32F4 ordering-pattern gap to 82 Base Devices and the policy-ready set to zero.

This phase is analysis-only. It does not change Production, broaden admission policy, or claim programming-algorithm equivalence from OpenOCD ordering-pattern routing evidence.

The first gate classifies every currently policy-blocked Base Device by the exact blocker(s) emitted by the current STM32F4 admission policy. The output is intended to answer a narrower question before any policy change is proposed: which blocker class provides the smallest, most defensible next expansion surface?

Any subsequent policy-extension proposal must separately justify package/pin metadata, flash-size semantics, exact commercial identity evidence, and unique OpenOCD routing. Physical PPU validation and IC Support programming-profile equivalence remain separate concerns.
