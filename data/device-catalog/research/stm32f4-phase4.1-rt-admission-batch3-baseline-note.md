# STM32F4 Phase 4.1 R/T Batch3 discovery boundary

This transaction is discovery-only until official ST browser acquisition has completed cleanly and a deterministic retained-evidence baseline has been reviewed.

Batch3 admission candidates are limited to these remaining Phase 4.1 R/T policy-ready Base Devices:

- STM32F411RC
- STM32F411RE
- STM32F413RG
- STM32F415RG

STM32F479ZG is retained as the admitted Active lifecycle control, so Batch3 contains five total pilot targets and remains below the hard `MAX_PILOT_TARGETS = 6` bound.

The remaining STM32F446 pair is intentionally deferred together to Batch4:

- STM32F446RC
- STM32F446RE

No production catalog row may be written from discovery output alone. OpenOCD ordering-pattern mapping is routing evidence only and is not a programming-algorithm-equivalence claim.
