26 deterministic STM32U0 Base Devices. The immutable raw browser evidence remains in
GitHub Actions artifact `10179167672` from workflow run `34545996184`.

Authority for U0.2 is the official ST **Quality & Reliability** table, where exact
`Part Number` and `Marketing Status` are co-located in the same manufacturer-controlled
row. The dynamically rendered Sample & Buy table does not gate commercial identity.

failures, zero manual-review targets, zero source-unavailable exclusions, and zero
non-Active lifecycle exclusions. The three U0.1 representative exact-ICPN sets showed
no drift.

programming-policy or algorithm equivalence, Flash geometry, option/security semantics,
physical HIL qualification, or runtime/PPU support.
