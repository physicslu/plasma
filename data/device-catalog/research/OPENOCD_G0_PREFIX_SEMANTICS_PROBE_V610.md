# OpenOCD STM32G0 Prefix-Semantics Probe v6.10

Research-only probe for the **12 STM32G0** Tier A residual identities that still have same-series route evidence but do not match the current G0 exact ordering-pattern policy.

The probe asks one narrow question:

> If STM32G0 used the same prefix-style ordering-pattern semantics already used by C0/L4/L1, would each blocked identity resolve to exactly one existing canonical OpenOCD route identifier?

This does **not** authorize a G0 policy change and does not modify Production.
