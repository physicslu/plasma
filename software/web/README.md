# Plasma Programmer Console

React/TypeScript Web Console for the Plasma multichannel programmer. The UI now
submits jobs to the Python HTTP Gateway, polls real job/channel status, and sends
cancel requests to the Python Job Manager. Progress is no longer generated by a
browser timer.

## Runtime path

```text
Browser -> Python HTTP Gateway -> Plasma v3.1 TCP Server -> MockInterface
```

The current prototype enables CH0 and CH1. CH2-CH7 remain visible but disabled
until they are configured by the Python server.

## Requirements

- Node.js `>=22.13.0`
- The Python Plasma Server and Web Gateway from `../python`

## Run locally

Start the Python processes first:

```bash
cd ../python
python -m plasma_server.server --config config/plasma.yaml
python -m plasma_web.gateway --host 127.0.0.1 --port 8080
```

Then start the UI in another terminal:

```bash
npm run install:ci
npm run dev
```

The default Python API URL is `http://127.0.0.1:8080`. Enter another URL in the
top bar when Python runs on a different computer, or set it at build time:

```bash
NEXT_PUBLIC_PLASMA_API_URL=http://192.168.1.50:8080 npm run dev
```

For a shared LAN, bind the Gateway to `0.0.0.0` and restrict CORS to the Web
origin, for example `--cors-origin http://192.168.1.20:5173`. CORS is not
authentication; do not expose this prototype Gateway directly to the Internet.

## Checks

```bash
npm run lint
npm test
npm run validate:artifact
```

`npm test` builds the Vinext/Cloudflare artifact, validates it, verifies the
server-rendered console, and confirms that the UI is wired to the Python API.
